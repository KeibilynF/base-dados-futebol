Este projeto consiste numa base de dados sobre futebol, criada para um trabalho escolar.
A base de dados inclui informações sobre competições, equipas, jogadores, treinadores, estádios e jogos.
O projeto contém o modelo MER, o modelo relacional e o código SQL utilizado para criar as tabelas e as relações entre elas.
O código foi testado em MySQL através do DB Fiddle.
